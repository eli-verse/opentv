# OpenTV 设计规范 v1

来源：cooimage/opendesign 无限画布 Figma 稿（规范页 node 640-151 + 交互稿 145:149）。
所有 UI 改动必须对照本规范；与本规范冲突的旧样式一律清除。

## 1. 色彩 — 单色系统

没有品牌彩色。整个产品只有黑、白、灰的透明度阶梯。

| Token | 值 | 用途 |
|---|---|---|
| `--otv-canvas-bg` | `#000000` | 画板背景（衬点阵网格） |
| `--otv-grid-dot` | `rgba(255,255,255,0.07)` | 画板点阵 |
| `--otv-card-bg` | `rgba(40,40,40,0.8)` | 卡片背景（#282828 80%） |
| `--otv-border` | `rgba(255,255,255,0.08)` | 描边 normal |
| `--otv-border-focus` | `rgba(255,255,255,0.6)` | 描边 focus / hover |
| `--otv-text` | `#ffffff` | 文字 主（激活/悬停） |
| `--otv-text-dim` | `rgba(255,255,255,0.4)` | 文字 辅助 |
| `--otv-btn-black` | `#151515` | 黑按钮 / 悬浮 pill 背景 |
| `--otv-btn-white` | `#ffffff` | 白按钮（主操作），disable 40% |

红色只用于错误提示与标注，永不做品牌色或装饰。

## 2. 文字

- 系统字体栈（PingFang SC / -apple-system / system-ui）
- 字号只有四档：**12 / 14 / 16 / 24**
- 字重只有两档：regular(400) / medium(500)

## 3. 形状与连线

- 卡片圆角 **16px**；悬浮操作条 pill 圆角全圆
- 媒体卡 = 作品本身：**无 header、无边框装饰**，图/视频满铺到圆角
- 连线是**细曲线**（灰、无夸张箭头），是系统画的血缘，不是用户画的流程
- 画板永远纯黑 + 点阵，卡片靠自身发光（媒体内容）分层

## 4. 组件模式

- **卡片操作悬浮化**：模型选择 / 重生成 / 变体 / 动起来放在卡片上方的悬浮 pill 里（#151515），不占卡片内部
- **提示词贴媒体**：完成态的提示词是媒体底部一条半透明 scrim 单行，可点改
- **衍生入口**：卡片近旁的 ⊕ / 操作条按钮，点击即派生新卡 + 自动连线
- **空画布引导**：居中 pill 提示（"双击开始"式），不用大插画
- 图标不用 emoji；用文字或单色线性图标

## 5. Do / Don't

- ✅ 黑白灰 + 内容即色彩：画面颜色只应来自用户生成的媒体
- ✅ 越少 chrome 越好，画布上只有作品和必要的操作
- ❌ 彩色渐变 header、彩色按钮
- ❌ emoji 当图标
- ❌ 白板残留（几何图形、便利贴等 tldraw 默认件）
